千里目 · 护眼提醒 —— 使用说明与免责声明
========================================

一、这是个什么软件
----------------------------------------
一款免费的个人自制护眼提醒小工具。
程序定时提醒您让眼睛休息一下；读取系统媒体播放状态，在您看视频时可以跳过提醒。

本软件为免费个人自制体验工具，仅供体验使用。


二、系统要求
----------------------------------------
· 原版 Windows 10 1703 及以上 / Windows 11（32 位、64 位均可）。
· 程序只使用 Windows 系统自带组件（Windows PowerShell 5.1、.NET Framework 4.x、
  WPF/WinForms），无需另外安装任何运行库，也无需联网。
· 注意：网络上流传的「精简版 / Ghost 精简系统」可能删除了 SMTC（系统媒体会话）
  组件，此时「播放视频时跳过提醒」的媒体识别功能会失效；
  其余计时与提醒功能不受影响。


三、功能介绍
----------------------------------------
· 统计有效屏幕使用时长，达到设定阈值后弹出休息提醒，引导您远眺放松。
· 读取 Windows 系统媒体会话（SMTC）的播放状态：确认正在播放带画面视频时，
  视为「有效用眼」，长时间不碰键鼠也不会被误判为「已离开」。
· 纯音频（音乐 / 播客）、视频会议、锁屏、显示器休眠，均不计入有效时长。
· 托盘常驻，右键可打开设置或退出。


四、数据与隐私（重要）
----------------------------------------
· 程序仅在本机运行，不会收集、上传任何用户个人信息或使用数据，全程无联网行为。
· 全部数据（配置、计时状态、运行日志）只保存在本机：
  D:\EyeRestReminder\data\  （本机没有 D 盘时自动改用 %LOCALAPPDATA%\EyeRestReminder\）
· 卸载时上述数据会一并删除。

· 本程序未购买代码签名证书。首次运行时 Windows 可能弹出蓝色 SmartScreen 警告

七、如何卸载
----------------------------------------
方式一：按 Win 键搜索「应用」→ 打开「设置 → 应用 → 已安装的应用」→
        找到「千里目 · 护眼提醒」→ 点击右侧「...」→ 卸载。
方式二：进入本程序安装目录，双击 unins000.exe。
方式三：开始菜单 → 千里目 → 右键 → 卸载（若提供）。

卸载会自动清理程序文件、快捷方式、开机自启动项、注册表卸载项，
以及位于 D:\EyeRestReminder\data 的本机数据。
