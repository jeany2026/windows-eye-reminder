千里目 · 护眼提醒 —— 使用说明与免责声明
========================================

一、这是个什么软件
----------------------------------------
一款免费的个人自制护眼提醒小工具。
程序按「有效用眼时长」计时，累计到设定阈值就提醒您让眼睛休息一下。

「有效用眼」包含两类：① 您在使用键盘 / 鼠标；② 您正在看带画面的视频。
请注意：看视频同样计时、到点同样提醒 —— 「看视频」并不会跳过提醒。
识别视频的目的，只是避免您长时间看视频、不动键鼠时被误判成「人已离开」。

会议 / 通话进行中不会打扰您：
  正在开视频会议、语音通话或视频通话时，即使累计时长到了提醒阈值也不会弹出
  提醒（本次跳过，并按与「弹窗关闭」完全相同的规则重新起算）；会议、通话本身
  也不计入用眼时长。

本软件为免费个人自制体验工具，仅供体验使用。


二、系统要求
----------------------------------------
· 原版 Windows 10 1703 及以上 / Windows 11（32 位、64 位均可）。
· 程序只使用 Windows 系统自带组件（Windows PowerShell 5.1、.NET Framework 4.x、
  WPF/WinForms），无需另外安装任何运行库，也无需联网。
· 注意：网络上流传的「精简版 / Ghost 精简系统」可能删除了 SMTC（系统媒体会话）
  组件。此时程序会降级为按「窗口标题 / 播放器进程」识别视频：本地播放器，以及标题
  中含视频关键词的网页（如「在线观看」「第01集」）仍能正常识别；但标题里看不出是
  视频的网页（例如只写了片名）可能识别不到 —— 这种时候若长时间看视频又不碰键鼠，
  会被空闲判定当成「人已离开」而触发计时清零（已累计的时长会一并清掉），
  提醒可能因此推迟或不来。其余计时与提醒功能不受影响。


三、功能介绍
----------------------------------------
· 按「有效用眼时长」计时：您在使用键鼠，或正在看带画面的视频，都算在用眼；
  累计达到设定阈值后弹出休息提醒，引导您远眺放松。
· 识别「正在看视频」，是为了不把「长时间看视频」误判成「人已离开」——
  看视频时提醒照常弹出，不会跳过。
· 「会议 / 通话进行中」自动免打扰：开视频会议、语音通话、视频通话期间不会弹出
  提醒，这些活动也不计入用眼时长。识别依据是系统音频会话（会议软件是否占用
  麦克风），不读取任何窗口内容与屏幕画面 —— 会议窗口缩成悬浮小条、最小化到
  托盘都同样有效；只打开会议软件主界面（未入会）则不会被视为开会。
· 纯音频（音乐 / 播客）不算「看视频」，不会延长用眼计时。
· 锁屏、显示器休眠、刚开机的宽限期内，计时整体暂停。
· 托盘常驻，右键可打开设置或退出。


四、数据与隐私（重要）
----------------------------------------
· 程序仅在本机运行，不会收集、上传任何用户个人信息或使用数据，全程无联网行为。
· 程序不截屏、不录屏、不读取窗口内容；仅查询「哪个进程正在占用麦克风」这一
  系统状态，不录制也不保存任何声音。
· 全部数据（配置、计时状态、运行日志）只保存在本机：
  D:\EyeRestReminder\data\  （本机没有 D 盘时自动改用 %LOCALAPPDATA%\EyeRestReminder\）
· 卸载时上述数据会一并删除。

六、已知限制与注意事项
----------------------------------------
· 精简版 Windows：缺少 SMTC 组件时会降级为按「窗口标题 / 播放器进程」识别视频；
  标题里看不出是视频的网页可能识别不到，若此时长时间看视频又不碰键鼠，会被空闲
  判定当成「人已离开」而清零计时（已累计的时长一并清掉，提醒可能因此推迟或不来）。
  其余功能不受影响。
· 会议 / 通话识别以「会议软件是否占用麦克风」为依据，因此存在两类识别不到的情况：
  ① 在浏览器网页里开会 / 通话时，占用麦克风的是浏览器，不在识别范围内；
  ② 个别会议软件在完全静音或最小化后可能释放麦克风。
  以上情况会按普通场景处理，即仍可能弹出提醒。
· 本程序未购买代码签名证书。首次运行时 Windows 可能弹出蓝色 SmartScreen 警告
  「Windows 已保护你的电脑」——点击「更多信息 → 仍要运行」即可，
  这是未签名程序的正常提示，不是病毒。
· 计时结果为软件估算，仅供参考，不构成医学建议。


七、如何卸载
----------------------------------------
方式一：按 Win 键搜索「应用」→ 打开「设置 → 应用 → 已安装的应用」→
        找到「千里目 · 护眼提醒」→ 点击右侧「...」→ 卸载。
方式二：进入本程序安装目录，双击 unins000.exe。
方式三：开始菜单 → 千里目 → 右键 → 卸载（若提供）。

卸载会自动清理程序文件、快捷方式、开机自启动项、注册表卸载项，
以及位于 D:\EyeRestReminder\data 的本机数据。
